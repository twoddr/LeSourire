Le Sourire — installation rapide (Windows)
==========================================

Prérequis
---------
- MariaDB (ou MySQL) installé et démarré sur le PC serveur du cabinet.
- Première install : exécutez une fois sql\01_creer_bd.sql
  (mysql -u root -p < sql\01_creer_bd.sql).
- Ce dossier contient une JRE Java 21 dans jre-windows\.
  Si le dossier est vide, copiez-y une JRE 21 (voir JRE-A-COPIER.txt).

Premier démarrage (PC principal / serveur)
------------------------------------------
1. Ouvrez serveur\lesourire-serveur.conf.bat et vérifiez :
   - URL MariaDB (défaut jdbc:mariadb://localhost:3306/lesourire)
   - utilisateur / mot de passe (défaut admin / csa-soft)
   - port Le Sourire (défaut 8420)

2. Double-cliquez : 1-Demarrer-Serveur.bat
   Le serveur démarre sans fenêtre ; ses logs sont écrits dans
   serveur\logs\lesourire-serveur.log.
   Pour l'arrêter : double-cliquez Arreter-Serveur.bat.

3. Double-cliquez : 2-Demarrer-LeSourire.bat
   Connexion : admin / admin
   Adresse serveur = http://localhost:8420
   (ou http://ADRESSE-DU-PC:8420 depuis un autre poste).
   Le client se lance sans console ; en cas de souci, consultez
   client\logs\lesourire-client.log (ou 2-Demarrer-LeSourire-debug.bat
   pour voir la console).

Un seul PC
----------
Vous pouvez utiliser ToutDemarrer.bat :
cela lance le serveur (fenêtre masquée), affiche une progression pendant
l'attente, puis lance le client — uniquement lorsque le serveur est prêt
(même si le premier démarrage, migrations comprises, prend du temps).
Arrêtez le serveur avec Arreter-Serveur.bat.

Postes clients supplémentaires
------------------------------
- Copiez seulement le dossier client + jre-windows + 2-Demarrer-LeSourire.bat
  (ou tout le dossier lesourire-windows).
- Dans l’écran de connexion, ouvrez « Adresse du serveur » :
  http://192.168.1.10:8420

Mise à jour (ne jamais remplacer que les .jar)
----------------------------------------------
1. Arrêtez le serveur : Arreter-Serveur.bat
2. Sauvegardez la base (module Sauvegardes du client, ou mysqldump) et vérifiez
   que « fichiers\cle-chiffrement.key » est bien présent.
3. Décompressez le nouveau paquet dans un dossier hors « Program Files » et hors
   OneDrive, puis recopiez votre configuration :
   serveur\lesourire-serveur.conf.bat (URL MariaDB, identifiants, port).
4. Conservez telles quelles :
   - « fichiers\cle-chiffrement.key » : la clé qui relit les données déjà
     chiffrées. NE LA REMPLACEZ JAMAIS par celle d'un autre paquet, et ne
     décompressez jamais un nouveau paquet ailleurs en laissant l'ancienne clé
     derrière vous ;
   - le dossier « sauvegardes\ » (et « serveur\sauvegardes\ » des versions 0.1.x,
     où les dumps étaient écrits).
5. Relancez : 1-Demarrer-Serveur.bat
   Flyway applique les migrations manquantes. Le serveur refuse de démarrer si
   la clé ne peut pas relire les données existantes : c'est voulu, cela évite
   d'écrire des données définitivement illisibles.

Outils de dépannage (livrés avec le paquet)
-------------------------------------------
- ToutDemarrer.bat : démarre le serveur en arrière-plan, puis le client.
- Lancer-Serveur-Debug.bat : démarre le serveur dans une FENÊTRE VISIBLE ;
  tout s'affiche à l'écran et le message d'erreur reste affiché. À utiliser dès
  qu'un démarrage échoue, au lieu de chercher dans le journal.
- Sauvegarder-Base.bat : sauvegarde la base (.sql) ET la clé de chiffrement,
  sans passer par le client. Ces deux fichiers vont toujours ensemble.
- Diagnostic-Chiffrement.bat : inventorie les clés de chiffrement du PC et
  vérifie que les données sont relisibles (rapport DIAGNOSTIC-CHIFFREMENT.txt).
- Arreter-Serveur.bat : arrête le serveur lancé en arrière-plan.

Au lancement, 1-Demarrer-Serveur.bat affiche le dossier utilisé, la VERSION du
paquet et l'empreinte de la clé : vous savez toujours quelle installation tourne.
Les espaces dans le chemin du dossier (par exemple « Logiciel Le Sourire ») sont
acceptés. Le chemin exact du dossier des sauvegardes est écrit au démarrage dans
serveur\logs\lesourire-serveur.log (ligne « Sauvegardes : dossier … »).

Chiffrement des données sensibles
---------------------------------
Les identités et données médicales sont chiffrées en base (AES-256-GCM). La clé
vit dans « fichiers\cle-chiffrement.key » et DOIT être sauvegardée avec la base :
sans elle, les données sont définitivement illisibles (une sauvegarde de la base
seule ne suffit pas). Le dossier « fichiers\ » ne doit jamais être supprimé, ni
laissé derrière lors d'un changement de dossier.

En cas de doute (erreurs sur les listes, serveur qui refuse de démarrer,
réinstallation), lancez l'outil de secours :
    Diagnostic-Chiffrement.bat
Il écrit DIAGNOSTIC-CHIFFREMENT.txt : clés trouvées sur la machine (empreintes),
compatibilité de chaque colonne, et la marche à suivre. Il ne modifie rien tant
que vous ne demandez pas « --rechiffrer ... --je-confirme ».

Dépannage
---------
- « Le serveur n'est pas lancé » : vérifier que 1-Demarrer-Serveur.bat
  a bien été lancé (Arreter-Serveur.bat indique s'il tourne), que le pare-feu
  autorise le port 8420, et consulter serveur\logs\lesourire-serveur.log.
- « Java Runtime introuvable » : dossier jre-windows manquant.
- « Clé de chiffrement incompatible » dans le journal : ne saisissez plus de
  données, restaurez la clé d'origine dans fichiers\cle-chiffrement.key (ou
  lancez Diagnostic-Chiffrement.bat) puis relancez le serveur.
- « Le client ne démarre pas » : consulter client\logs\lesourire-client.log.
- Erreur BD : MariaDB démarré ? Identifiants dans lesourire-serveur.conf.bat ?
  Script sql\01_creer_bd.sql exécuté (créé aussi l’utilisateur lesourire@localhost) ?
